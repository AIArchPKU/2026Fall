# Hardware Architecture for Intelligent Computing Systems @PKU — Fall 2026

Course website for the Fall 2026 offering at Peking University.

## Local preview

```bash
bundle install
bundle exec jekyll serve --baseurl /2026Fall
```

The site will be available at `http://127.0.0.1:4000/2026Fall/`.

## Updating course content

- Copy the examples in `_templates/` into `_lectures/`, `_assignments/`,
  `_announcements/`, or `_events/` and update their front matter.
- Put slides in `static_files/presentations/`, assignments in
  `static_files/Assignments/`, and lab handouts in `static_files/Lab/`.
- Update the teaching team in `_data/people.yml` and confirmed policy text in
  `_data/late_policy.yml`.
